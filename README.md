TASK MANAGER WEB APPLICATION

The project is a task manager, where you can:

1-Create tasks
2-Update tasks
3-Delete taks

Each task has:

-Title
-Description (optional, by default 'Not defined')
-Status (completed, pending, in progress)
-Priority (low, medium, high)
-Creation Date (defined in the backend to avoid unexpected data to be sent to the database)
-Due Date

In addition to that, in the web app you can search tasks by their name, filter them, and choose the order
in which they appear.

Technologies used:

-HTML
-CSS
-JavaScript
-ReactJS
-TypeScript
-NodeJS
-SQLite3
